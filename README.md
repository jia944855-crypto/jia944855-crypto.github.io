## 怎么打开看效果

双击 `index.html` 就能在浏览器里打开。

如果图片显示不出来，用本地服务器打开（在项目文件夹里执行）：

```bash
python3 -m http.server 8777
```

然后浏览器访问 `http://localhost:8777/index.html`。

## 翻译处理说明

不是逐字直译，而是按中文旅游文案的习惯重写，同时保留原站「斜体小引子 + 大字主标题」的排版节奏：

| 原文 | 译文 | 说明 |
|------|------|------|
| Welcome to / the unseen beauty of Santorini | 欢迎来到 / 圣托里尼，未被看见的美 | 保留两行结构 |
| A wonder to / discover in the Aegean | 一座值得你 / 远赴爱琴海去发现的岛 | 把名词短语转成更自然的中文句式 |
| Spots worth visiting | 这些地方 / 一定不要错过 | 口语化，比「值得参观的地点」更像中文旅游站 |
| Indulge in nature's plate. | 把大自然，端上餐桌。 | 意译，保留原文的俏皮感 |
| Past till Future | 从远古一路通向未来 | 补足中文需要的动词 |

**美食板块做了扩写**：原站这一段直接复制了徒步板块的英文（原文本身的错误），中文版改写成了真正讲圣托里尼美食的内容（圣岛番茄、黄豌豆泥、阿斯提可葡萄酒）。

**图片处理**：博客第三张图原图上压着英文标语「BEST ISLAND in Europe」，用 CSS 裁切到了右侧，只保留风景部分，避免中文页面里混入英文。
